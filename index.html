How independent sizing works

Change the global cell dimensions in Section 2 to change the grid. Select a single image in the list and change its width, height, fit mode, or offset in Section 3 to change only that image. “Fit inside cell” is recommended for images with different aspect ratios because it displays the entire image without stretching or cropping.
